# Keyboard

Every control works from the keyboard, and the main actions have shortcuts.

## Shortcuts

| Keys | What they do |
|---|---|
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> | Show or hide Pixel Veil, like the toolbar icon |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> | Hide or show all layers |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>.</kbd> | Active layer 10 % more solid |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>,</kbd> | Active layer 10 % more see-through |
| Arrow keys | Move the active layer 1 px; with <kbd>Shift</kbd>, 10 px |
| <kbd>F2</kbd> on a layer's name | Rename the layer |
| None set | Switch Difference on or off: pick your own keys |

Change any of them, or give Difference its own keys, at `chrome://extensions/shortcuts`.

## The panel from the keyboard

- <kbd>Tab</kbd> moves through the panel's controls. The panel draws a ring around the one in focus.
- <kbd>Enter</kbd> or <kbd>Space</kbd> on a layer's name makes that layer active.
- After you click or choose a layer's row, the arrow keys move that layer.
- In a text or number field, the arrow keys stay in the field.

## With a screen reader

The panel is a named region with a heading. Every control has a name rather than a symbol, and each row's buttons name the layer they act on: "Move design up", "Delete design". An error, such as a refused image, is read out as it appears.
