# Roadmap

This is the shape of the journey, not its current state — the day-to-day backlog of specific
tasks is a maintainer's working material and is not published (see [PUBLIC.md](PUBLIC.md)).
This file is the only forward-looking view a reader outside the project gets, so keep it
honest: an empty milestone is more useful than a stale one.

## M0 — Bootstrap

The repository exists, the licence in [LICENSE](LICENSE) has been chosen, and the basics work.

## M1 — First usable version

Any number of design layers over a live page: see-through level, position, nudge, scale, lock,
per-site memory, a difference view, and layers that return after a reload on sites you keep.

## M2 — Hardening

The rough edges found by actually using M1 are closed, and the things it deliberately does not
do yet are written down here rather than discovered by surprise.

## M3 — Public release

Ready for someone outside the project to pick up, use, and report a problem against.

## Things deliberately not coming

- **A layer limit.** Every layer is free, and stays free.
- **An account or a server.** Images and settings stay in the browser.
- **Access to every site at install.** Site access is asked for one site at a time.
